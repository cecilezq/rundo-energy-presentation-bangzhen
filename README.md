## 发布方式

GitHub Pages 使用 GitHub Actions 发布。`scripts/build_site.py` 在到期前复制演示稿，到期后清空部署目录并仅生成到期提示。

演示图片保留原图，点击可放大；方向键翻页，底部提供目录和中文演讲备注。
